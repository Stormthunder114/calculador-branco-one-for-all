Como funciona a atualização?

O One For All consulta diretamente a API oficial da Blitz, sem parâmetros de data, conforme o endereço que você testou. Quando o serviço permite leitura, atualiza aproximadamente a cada 2 minutos com a aba ativa. O celular pode suspender atualizações em segundo plano.
