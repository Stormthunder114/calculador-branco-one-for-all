Como funciona? Em cada hora, identificamos o primeiro par de amarelos seguidos. As próximas 11 rodadas são observadas. O primeiro branco encerra a contagem; se nenhuma for branca, é falha. Se faltarem dados, não pontuamos.

Por que não é a API oficial? Embora o teste inicial da Blitz tenha retornado 100 registros (HTTP 200), uma consulta automática posterior retornou HTTP 451 em 15/11/2026. A integração automática direta foi suspensa; não fazemos tentativas para contornar essa restrição.

Como atualiza? O GitHub consulta uma amostra pública do Históricos Blaze uma vez por hora, respeitando robots.txt e as restrições do serviço. Nosso site lê a cópia publicada no GitHub e a verifica a cada 10 minutos. O botão apenas recarrega essa cópia.

Por que pode atrasar? A fonte pode ter lacunas, ficar indisponível ou mudar de formato. Nesse caso, preservamos os resultados anteriores e sinalizamos o problema. Sem dados completos, a hora não conta como acerto ou falha.

De onde vêm os resultados? Fonte externa: Históricos Blaze — Double Blitz. Não somos afiliados a esse serviço. A cor vermelha (números 1–7) é exibida como amarela (cor 1), seguindo o nome usado neste experimento.

O que acontece com os dados? O GitHub mantém uma amostra limitada e este navegador guarda seu histórico coletado. O resumo anterior de 3 acertos em 5 testes não contém as rodadas originais.

Ferramenta de pesquisa descritiva. Um resultado anterior não permite saber quando virá o próximo branco e não demonstra vantagem estatística.
